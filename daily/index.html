For the person who updates the plan

Edit plans.json in this folder. Add one ready day when the lesson and the print packet are approved. Both child links read that same day. Wording for each page also lives in that file. Do not add tasks to the HTML files.

The field list is in README.md.

What stays on the device

Checks and notes are saved in the browser only. This page does not show them. Send to Mom opens the device share sheet when the browser has one. The child chooses the app and the person. This site does not send the summary.

About the links

A separate link is not a login. If this site is public, anyone who has a link can open that checklist. They still cannot see checks or notes saved on someone else's phone.
